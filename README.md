# CISC204-S26-Project3-Template
This project lets people create their own characters. It was created as a part of a character creator assignment for my Introduction to Game Development class.


In order to make this project, I had to make a series of images and make only one of them visible at the start.
Then I had to make it so that when a left or right button was pressed, the next or previous image would display, depending on what button was pressed.
I had to do this three times for the head, the torso, and the legs.
After this, I had to find a way to save and load my options.
To do this, I implemented variables to save my options in and when the save button was pressed, the options chosen would save.
Then I made it so that when the load button was pressed, it would give off a series of signals that would make the options that were saved show up on the screen.
Also, I had to make the options appear on the screen as a series of numbers, so I had the customization options for the head, torso, and legs appear as numbers and when the options changed, the number would increase or decrease depending on which button was pressed or which number was entered.
Lastly, I had to make another feature to adjust visibility, so I made a check toggle so that when it was toggled on, the character would turn red.


While I was making this project, I learned how to save and load things.
I also learned how to cycle through visual elements, like images.
Another thing I learned while making this project was how to make a check toggle work.
One of the hardest things I learned to do while making my character creator was how to cycle back to the beginning when a certain index was reached. 
This took me a few tries, but I eventually got it to work.
One of the most interesting things I learned was how to properly input text and have it change something in the game.
I found it interesting because I had never actually done anything like that in Godot before, so it was a new experience for me.
Lastly, I learned how to update things in real time, such as a string of numbers.


If I was given more time or I could start this whole project all over again, I would add sounds to my project. I would also give the heads, torsos, and legs some more motion by replacing the static 2D sprites that were used for their respective scenes with animated 2D sprites.
